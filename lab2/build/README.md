# build 目录

## 说明
本目录由判题机自动维护，用于存放编译产物、诊断日志以及 Windows 兼容性转译副本。

## 目录结构
```text
build/
└── <学号>/
    ├── lab2_1.bin              # 编译成功的可执行文件
    ├── lab2_1_compile.log      # 完整编译命令、输出与耗时日志
    ├── lab2_2_compat.c         # 若学生包含 Windows 头文件/语法，生成的自动兼容转译副本
    └── ...
```

## 工作流提示
- 本目录完全由编译引擎自动生成。
- 重新测试时，可直接删除本目录（或使用 `python3 -m checker --lab lab2 --clean` 自动清空）。
- 本目录除本 `README.md` 外，已被 `.gitignore` 忽略，开源时不会提交任何二进制产物或日志。
