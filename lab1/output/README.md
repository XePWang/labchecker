# output 目录

## 说明
本目录用于存放判题完成后的最终成果与报表产物。

## 生成文件契约
- **lab1结果.csv**: 逐人、逐题评测明细表（含编译状态、测试用例通过率、AI 评审得分与复核标记）。
- **lab1报告.md**: 批次分析报告（含应交/实交统计、平均分、满分率、常见逻辑/环境错误分析及待人工复核清单）。
- **lab1实验成绩单.csv**: 严格按花名册顺序生成的标准成绩表（包含学号、姓名、总分及每人不少于 50 字的定制评语）。
- **lab1实验成绩单.xlsx**: 若提供了官方 Excel 模板，自动回填对应工作表生成的最终版成绩单。

## 工作流提示
- 重新测试时，可直接删除本目录（或使用 `python3 -m checker --lab lab1 --clean` 自动清空）。
- 本目录除本 `README.md` 外，已被 `.gitignore` 忽略，开源时不会提交任何真实学生成绩。
