# submit 目录

## 说明
本目录用于存放待评测的原始提交文件（从课程收集平台如 WPS 群收文件、教学系统直接导出的学生作业）。

## 支持格式
- `.zip` 压缩包（例如 `班号_姓名_学号_实验1.zip`，判题机具备自动防 Zip Slip 穿越和 Windows GBK 文件名转码能力）
- 未打包的子目录（例如 `班号_姓名_学号_实验1/`）
- 散放的代码文件与演草纸图片（例如 `学号_Lab 1-2.c`、`学号_验算.jpg`）

## 工作流提示
- 本目录为只读归档目录，评测流水线会自动从中提取并规范化至 `src/`。
- 本目录除本 `README.md` 外，已被 `.gitignore` 忽略，重新评测时可清空本目录并拉取最新提交包。
